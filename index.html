Modo APK Nativo vs Web Bluetooth

    

      

        
✅ APK Modificado (Recomendado)

        
Usa el protocolo nativo descubierto por ingeniería inversa:

        
    
          
  • AES-128-ECB con clave fija
    • 
          
  • Handshake ed3823c3... obligatorio
    • 
          
  • Chunks 810F + frame + part + data
    • 
          
  • Más estable, soporte para ACKs
    • 
        

        
Requiere que el dispositivo ya esté emparejado en Android.

      

      

        
⚠️ Web Bluetooth (Fallback)

        
Usa la API estándar del navegador:

        
    
          
  • Funciona en Chrome/Edge en Android
    • 
          
  • El Nachimbong V2 puede rechazar la conexión
    • 
          
  • No requiere APK modificado
    • 
          
  • Menos confiable con este dispositivo
    • 
        

      

    


    
Formato nachimbong (detectado por ingeniería inversa)

    
Skin = Array<Frame>          // típicamente 16 frames
Frame = string hex 512 chars  // = 256 bytes
Layout: SSD1306 page-byte, LSB arriba.
   - 4 páginas verticales (32 px / 8)
   - 64 columnas
   - Byte[p*64 + x] codifica los 8 píxeles verticales
     de la columna x en la página p (bit 0 = arriba).


    
Solución de problemas

    
    
      
  • "No Services matching UUID" → El dispositivo se desconecta inmediatamente. Emparéjalo primero desde Ajustes de Android.
    • 
      
  • "GATT Server disconnected" → El lightstick requiere autenticación nativa. Usa el APK modificado.
    • 
      
  • "Bridge no disponible" → Abre esta web dentro del APK modificado, no en el navegador estándar.
    • 
      
  • El lightstick se apaga al enviar → Batería baja o el protocolo nativo no está respondiendo. Revisa que esté emparejado.
