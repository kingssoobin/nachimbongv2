Documentación rápida

    
    
      
  1. Importar una imagen o GIF animado. Si es un GIF, cada frame se conserva. Si es estático, se duplica al nº de frames indicado.
    2. 
      
  2. En Ajustar, configura encaje, rotación, brillo/contraste y el algoritmo de dithering. Floyd–Steinberg da el mejor resultado para fotos.
    3. 
      
  3. En Previsualizar mira cómo se verá en el OLED real (escala configurable). Pulsa ▶ para animar.
    4. 
      
  4. En Exportar elige el formato:
        
      
          
    • Hex nativo: 16 frames × 256 bytes (compatible con el formato del bundle oficial).
      • 
          
    • .bin · Array C · JSON · U8g2 XBM.
      • 
        
    
      
    5. 
      
  5. Enviar: si usas el APK modificado, pulsa Conectar y el puente nativo se encargará del BLE. Si usas Chrome directo, intentará Web Bluetooth.
    6. 
    

    
Formato nachimbong (detectado por ingeniería inversa)

    
Skin = Array<Frame>          // típicamente 16 frames
Frame = string hex 512 chars  // = 256 bytes
Layout: SSD1306 page-byte, LSB arriba.
   - 4 páginas verticales (32 px / 8)
   - 64 columnas
   - Byte[p*64 + x] codifica los 8 píxeles verticales
     de la columna x en la página p (bit 0 = arriba).
